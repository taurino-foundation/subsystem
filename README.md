# Meet Taurino

### A Modern, Rust-Powered Desktop Framework for Python

**Python Simplicity. Rust Performance. Native Desktop Experiences.**

</div>

---

Taurino is a modern, cross-platform desktop application framework that brings together **Python's flexibility**, **Rust's performance**, and **web technologies** in a unified development environment.

Powered by **Tao and Wry**, Taurino provides a native, event-driven runtime with asynchronous execution, efficient inter-process communication (IPC), and seamless integration between Python, Rust, and JavaScript.

Built for developers who demand **performance, reliability, and flexibility**, Taurino makes it easier to create powerful desktop applications without compromising the simplicity and productivity of Python.
